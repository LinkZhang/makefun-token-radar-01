A token launch radar: every protocol in the DefiLlama snapshot that records no token, ranked by an implied value derived from its own TVL, 7-day growth, age and chain breadth, with a concrete farm plan per protocol and a sortable, filterable dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
